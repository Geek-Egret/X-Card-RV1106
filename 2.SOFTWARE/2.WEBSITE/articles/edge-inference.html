🧠 边缘推理网关

标签：AIoT / 边缘计算 / 推理
🧠

概述

构建轻量级边缘端 AI 推理网关，支持将训练好的模型部署到 RV1106 板卡上，实现本地实时推理，无需依赖云端。

核心功能

  • 支持 ONNX / RKNN 模型格式
  • 模型量化与优化工具链
  • RESTful API 接口
  • 多模型并行调度
  • 推理结果可视化面板

🏗️ 架构图

性能指标

  • MobileNetV2 推理延迟：< 10ms
  • YOLOv5s 推理延迟：< 50ms
  • 支持同时运行 3 个轻量模型
  • 典型功耗：< 2W

快速开始

# 转换模型为 RKNN 格式
python3 convert.py --input model.onnx --output model.rknn

# 启动推理服务
python3 server.py --model model.rknn --port 8080

# 调用 API
curl -X POST http://localhost:8080/infer \
  -H "Content-Type: application/json" \
  -d '{"image": "base64..."}'
