标签：Nginx / Web / RV1106

概述

geekegret Studio 是本工作室的官方网站，完全运行在 Rockchip RV1106 嵌入式板卡上。使用板卡自带的 Nginx 作为 Web 服务器，采用纯静态 HTML + CSS + JS 方案。

技术选型

  • Web 服务器：Nginx（板卡自带）
  • 前端：纯 HTML5 + CSS3 + Vanilla JS
  • 布局风格：仿 PaperMod 主题
  • 特色：SPA 客户端路由、明暗主题切换

性能

  • 页面总大小：约 20KB（gzip 后约 8KB）
  • 首屏加载时间：< 100ms（局域网）
  • 并发支持：Nginx 默认 1024 连接
  • 功耗：板卡整机 < 2W
# 部署命令
scp index.html root@192.168.1.9:/usr/html/
ssh root@192.168.1.9 "nginx -s reload"
