📡 低功耗传感器网络

标签：传感器 / 低功耗 / BLE
📡

概述

设计低功耗无线传感器网络，适用于环境监测、农业、工业等场景。节点采用 BLE 进行短距通信，通过 WiFi 网关汇聚数据上云。

技术路线

  • 传感器节点：低功耗 MCU + BLE 5.0
  • 网关：RV1106 + WiFi + BLE
  • 通信协议：MQTT-SN over BLE
  • 数据存储：本地 SQLite + 云端同步

传感器类型

  • 温湿度传感器（SHT30）
  • 光照传感器（BH1750）
  • 大气压力传感器（BMP280）
  • 土壤湿度传感器
  • PM2.5 传感器（PMS5003）

功耗目标

  • 节点待机功耗：< 10μA
  • 节点工作功耗：< 10mA
  • 纽扣电池续航：> 1年
