# 网站已支持 Markdown 文章

> 现在你可以直接编写 `.md` 文件作为文章，无需手工编写 HTML。

---

## 为什么选择 Markdown

Markdown 是一种轻量级标记语言，相比 HTML 有以下优势：

- **易读易写**：语法简洁，专注于内容而非排版
- **版本控制友好**：纯文本格式，Git diff 清晰可读
- **快速上手**：无需学习 HTML/CSS 即可撰写文章
- **离线可编辑**：任何文本编辑器都能打开

## 如何使用

### 1. 创建 Markdown 文件

在 `articles/` 或 `products/` 目录下创建 `.md` 文件，例如 `articles/my-post.md`。

### 2. 添加链接

在首页或其他页面中添加链接，指向你的 `.md` 文件：

```
<a href="/articles/my-post.md">我的文章</a>
```

如果不加扩展名，系统会自动尝试 `.html` 再尝试 `.md`。

### 3. 支持的语法

| 元素 | 语法 |
|------|------|
| 标题 | `# H1` `## H2` `### H3` `#### H4` |
| 粗体 | `**文本**` |
| 斜体 | `*文本*` |
| 删除线 | `~~文本~~` |
| 链接 | `[文本](URL)` |
| 图片 | `![替代](URL)` |
| 行内代码 | `` `code` `` |
| 代码块 | ` ``` ` |
| 列表 | `- 项目` 或 `1. 项目` |
| 引用 | `> 文字` |
| 表格 | `\| 列1 \| 列2 \|` |
| 分割线 | `---` |

## 技术实现

内置的轻量级 Markdown 解析器（约 2KB）支持常见语法，无需引入外部依赖，适合嵌入式场景。
