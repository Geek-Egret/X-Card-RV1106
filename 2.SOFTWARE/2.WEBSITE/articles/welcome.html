关于本站

GeekEgret Studio 网站正式上线，运行在 Rockchip RV1106 板卡上，由 Nginx 提供 Web 服务。所有页面均为纯 HTML 静态页面，不依赖任何前端框架。

网站功能

  • 首页：展示个人简介、社交链接、最新文章动态
  • 产品页：列出所有产品，支持按标签筛选
  • 文章页：列出所有文章，支持按标签筛选
  • 关于页：介绍工作室与技术栈
  • 联系页：提供联系方式

如何添加文章

  1. 在 articles/ 目录下创建 .html 文件，命名如 my-article.html
  2. 文件格式为 HTML 片段，外层用 <div class="page-content"> 包裹
  3. 标题使用 <h1> 标签，标签信息用隐藏的 <div class="entry-tags" style="display:none"> 声明
  4. 通过 scp 上传到板卡 /usr/html/articles/ 目录
  5. 首页和文章列表页会自动发现并展示

参数自定义

网站所有文本、链接、样式参数集中在 param.json 文件中，修改后 scp 到板卡即可实时生效。也可使用 python3 edit_param.py 交互式编辑。
